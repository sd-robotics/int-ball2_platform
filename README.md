# Int-Ball2 Control Platform

## Overview
Technology Demonstration Platform S/W for Int-Ball2 using ROS 2 and Nvidia's Isaac Sim.

For details see the [Int-Ball2 Simulator (Isaac Sim)](https://github.com/sd-robotics/int-ball2_isaac_sim) repository.
